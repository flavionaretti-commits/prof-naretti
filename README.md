Materiali, app didattiche, giochi e laboratori del prof. Flavio Naretti.

## Pubblicazione
In Settings → Pages scegliere Deploy from a branch, branch main, cartella / (root).

## Catalogo
Le risorse sono in catalog.json. Mantenere gli id stabili. Incrementare revision per segnalare aggiornamenti nei documenti Drive. Le risorse senza grades sono comuni alle classi.

Preferiti e letture sono salvati sul dispositivo. Il collegamento a un foglio Google non è ancora configurato.
